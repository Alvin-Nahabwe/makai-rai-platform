## How to answer

Reply with one line per row you want to settle: `<row>: accept`, `<row>: edit <your wording>` or `<row>: decline`. "Accept all the pre-processing rows" is also an answer. A row you leave unanswered stays undecided, and we come back to it before anything is signed.

Each label is read as the answer it is stored as: a Done label says the practice is in place, a Partly label starts "Partly" (on the two checklist questions, Q-PP-16 and Q-PP-17, it starts "Some of"), a Not yet label says "No, not yet" (or "None yet" for the two checklist questions), and a Not applicable label says, in neutral words, why the question does not apply: mostly "No <practice> applies", or a fact visible before the practice is done, such as "No data source is used". On the 17 questions whose typed text prints in the data card or model card (the 15 whose reason feeds a field, plus Q-PP-16 and Q-PP-17, whose typed reason prints with their ticks), every prompt asks for text that reads correctly there and says which document it prints in.
