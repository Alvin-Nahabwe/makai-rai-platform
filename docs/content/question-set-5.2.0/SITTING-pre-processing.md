## How to answer

Reply with one line per row you want to settle: `<row>: accept`, `<row>: edit <your wording>` or `<row>: decline`. "Accept all the pre-processing rows" is also an answer. A row you leave unanswered stays undecided, and we come back to it before anything is signed.

Each label is read as the answer it is stored as: a Done label says the practice is in place, a Partly label starts "Partly", a Not yet label says "No, not yet" (or "None yet" for the two checklist questions), and a Not applicable label says, in the question's own words, that the practice does not apply ("Does not apply to this project" on Q-PP-11 and Q-PP-14, where no other wording fits). On the 15 questions whose typed text prints in the data card or model card, every prompt asks for text that reads correctly in that field and says which document it prints in.
