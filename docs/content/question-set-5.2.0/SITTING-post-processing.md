## How to answer

Reply with one line per row you want to settle: `<row>: accept`, `<row>: edit <your wording>` or `<row>: decline`. "Accept all the post-processing rows" is also an answer. A row you leave unanswered stays undecided, and we come back to it before anything is signed.

Each label is read as the answer it is stored as: a Done label says the practice is in place, a Partly label starts "Partly" (or "Some of" for the checklist Q-PO-11), a Not yet label says "No, not yet" (or "None yet" for Q-PO-11), and a Not applicable label says, in the question's own words, that the practice does not apply. A system not yet in use is Not yet, as in 5.1.0: on Q-PO-01 the Not applicable label is 5.1.0's own condition, "It will never be used outside the study"; on Q-PO-02 it says retraining "will never apply"; on Q-PO-17 the Not applicable prompt says so. On the 3 questions whose typed text prints in the model card (Q-PO-01 and Q-PO-02 in "Monitoring requirements and retraining triggers", Q-PO-15 in "Deployment recommendations"), every prompt asks for text that reads correctly there and says it prints in the model card; those fields print the answer beside the text. 5.1.0's reason prompts gave one prompt for every answer; their cautions (never by name, roles not people, no uploads that identify people, no personal details, the platform makes no judgement) now sit in the prompts of the answers they concern.
