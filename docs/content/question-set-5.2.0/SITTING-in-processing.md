## How to answer

Reply with one line per row you want to settle: `<row>: accept`, `<row>: edit <your wording>` or `<row>: decline`. "Accept all the in-processing rows" is also an answer. A row you leave unanswered stays undecided, and we come back to it before anything is signed.

Each label is read as the answer it is stored as: a Done label says the practice is in place, a Partly label starts "Partly" (or "Some of" for the two checklist questions), a Not yet label says "No, not yet" (or "None yet" for the two checklist questions), and a Not applicable label says, in the question's own words, that the practice does not apply. On the 7 questions whose typed text prints in the model card (Q-IP-01, Q-IP-02, Q-IP-06, Q-IP-08, Q-IP-15, Q-IP-19, Q-IP-20), every prompt asks for text that reads correctly in that field and says it prints in the model card. Q-IP-06 and Q-IP-20 print without the answer beside them, so their Not yet and Not applicable prompts ask for a sentence that says so itself. Q-IP-03, Q-IP-04, Q-IP-12 and Q-IP-13 feed the model card through evidence or a ticked option; their prompts keep 5.1.0's line on that.
