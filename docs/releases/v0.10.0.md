### What a person will see

- **Who and when are filled in.** Before Save, the answer form shows one line: "Decided by you, <today> · Change". **Change** opens the Decided by and Decided on fields and moves focus into them. Nothing is filled in on the server, so what will be recorded is always on screen.
  - A browser draft from v0.9.0 with a date typed in keeps that date and its decider. One with no date restores as "Decided by you, <today>" (the security review's L-2).
  - When an earlier answer is changed, the line shows the earlier decider and today's date.
- **The reason is optional for answers.** The decision card, the working report and documents print no "Reason:" line for an answer without one.
  - Withdrawals (FR-DEC-08) and accepted risks (FR-FND-05) still require a reason.
  - Not yet and Not applicable still require a main reason (the reason code).
- **Save moves on.** A clean save opens the next unanswered question in the stage, or the stage's end screen when none is left. The new page starts with "Your answer to question N is saved: decided by <who>, <date>. Back to question N", shown only to the person who entered the answer.
  - A save whose message the person must read stays on the question. So does a save while a link or file is still uploading.
  - The move goes through a redirect-only address, `/orgs/<slug>/projects/<id>/stages/<stage>/next` (UX-44). It renders no page of its own.
- **Next** is a link drawn as a secondary button, "Next: <words>"; Save is the page's one primary action.
